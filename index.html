Panduan Admin Panel Administrasi

Selamat datang di panduan resmi untuk panel admin administrasi. Panduan ini akan membantu Anda mengelola staff, rekening admin, gaji staff, dan bonus staff dan juga membantu Anda untuk memproses gaji staff.

Login & Akses

Untuk mengakses panel, masuk ke /auth/webmaster-login di browser Anda.

  • Username: Username yang diberikan IT support
  • Password: Password yang diberikan IT support
Note: Jika Anda kehilangan password, silakan hubungi IT support secara langsung.

Ringkasan Dasbor

Setelah login, anda akan melihat dasbor utama. Terdapat fitur sebagai berikut :

  1. Status Gaji : Data gaji per periode pada saat ini yang sudah dan belum diproses.
  2. Kalender: Kalender bulan dan periode per saat ini.
  3. Tombol Menu: Tombol menu untuk mengakses fitur-fitur yang ada pada panel.

Manajemen Rekening Admin

Anda dapat melakukan tindakan berikut di menu rekening admin:

Aksi Deskripsi Contoh
Tambah Bank ( Plus ) Tambah data rekening admin ( Jenis bank, nama rekening, nomor rekening dan status ).
Edit ( Pensil ) Set dan ubah data rekening admin ( Jenis bank, nama rekening, nomor rekening dan status ).
Hapus ( Tong Sampah ) Hapus data rekening admin.
Status ( Dropdown ) Saring rekening admin dari status ( aktif / non-aktif / semua ). -
Saring ( Dropdown ) Saring rekening admin berdasarkan jenis bank. -

Manajemen Staff

Anda dapat melakukan tindakan berikut di menu staff:

Aksi Deskripsi Contoh
Edit ( Pensil ) Set dan ubah rekening gaji staff ( Jenis bank, nama rekening dan nomor rekening ).
Status ( Dropdown ) Saring staff dari status ( aktif / non-aktif / semua ). -
Saring ( Dropdown ) Saring staff berdasarkan situs. -

Fitur sinkronisasi data staff manual dapat diakses melalui tombol yang terletak di navbar kanan, tepat di sebelah kiri menu pemilihan bahasa.

Manajemen Gaji Staff

Anda dapat melakukan tindakan berikut di menu gaji staff:

Aksi Deskripsi Contoh
Edit ( Pensil ) Set dan ubah nominal gaji dan subsidi staff.
Detail ( Mata ) Catatan riwayat perubahan gaji staff.
Ubah Gaji Massal Set dan ubah nominal gaji dan subsidi staff secara massal.
Ubah Pengaturan Subsidi Set dan ubah pengaturan subsidi.
Ubah Tanggal Sah CS ( kalender ) Set dan ubah tanggal sah CS staff.
Saring ( Dropdown ) Saring staff berdasarkan situs. -

Proses Gaji Staff

Anda dapat melakukan tindakan berikut di menu proses gaji staff:

Aksi Deskripsi Contoh
Proses ( Biru ) Konfirmasi pembayaran gaji staff.
Detail ( Centang Hijau ) Riwayat lengkap pembayaran gaji staff.
Ekspor ke Excel Download dan simpan data gaji yang sudah dibayar ke excel sesuai dengan periode yang dipilih. -
Perbarui Data Gaji ( Refresh ) Manual perbarui data gaji staff.
Pilih Periode ( Dropdown ) Pilih periode bulan yang ingin dilihat. -
Saring ( Dropdown ) Saring staff berdasarkan situs. -

Manajemen Bonus Staff

Aksi Deskripsi Contoh
Edit ( Pensil ) Set dan ubah bonus mentah staff.
Ubah Bonus Massal Set dan ubah bonus mentah staff secara massal.
Saring ( Dropdown ) Saring staff berdasarkan situs. -

Manajemen Bonus Periode ( Berjalan )

Anda dapat melakukan tindakan berikut di menu bonus periode:

Aksi Deskripsi Contoh
Hitung Ulang Bonus ( Refresh ) Menghitung kembali bonus periode staff secara manual. -
Saring ( Dropdown ) Saring bonus periode staff berdasarkan tahun, periode, dan situs. -

Manajemen Bonus Periode ( Terkunci )

Anda dapat melakukan tindakan berikut di menu bonus periode:

Aksi Deskripsi Contoh
Dikunci Mengubah bonus staff secara manual.
Detail ( Mata ) Melihat detail bonus periode staff.
Saring ( Dropdown ) Saring bonus periode staff berdasarkan tahun, periode, dan situs. -
